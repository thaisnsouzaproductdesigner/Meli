# Transições & Animações

## Sistema de Motion Design

Este sistema define os princípios, durações e easings padrão para todas as animações da documentação.

## Escala de Durações

```css
/* Ultra-rápido - Micro-interações */
duration-75: 75ms

/* Rápido - Hover states, tooltips */
duration-100: 100ms
duration-150: 150ms

/* Médio - Transições de UI */
duration-200: 200ms
duration-300: 300ms

/* Lento - Modals, overlays */
duration-500: 500ms
duration-700: 700ms
```

### Quando Usar Cada Duração

- **75-100ms**: Hover states, highlights
- **150-200ms**: Botões, inputs, micro-animações
- **300ms**: Transições padrão, cards, dropdowns
- **500-700ms**: Modals, side panels, page transitions

## Curvas de Easing

```css
/* Linear - Raramente usado */
ease-linear: linear

/* Ease - Padrão para maioria das transições */
ease: cubic-bezier(0.4, 0, 0.2, 1)

/* Ease-in - Elementos que saem da tela */
ease-in: cubic-bezier(0.4, 0, 1, 1)

/* Ease-out - Elementos que entram na tela */
ease-out: cubic-bezier(0, 0, 0.2, 1)

/* Ease-in-out - Movimentos completos */
ease-in-out: cubic-bezier(0.4, 0, 0.2, 1)
```

### Curvas Personalizadas

```css
/* Spring - Efeito elástico suave */
cubic-bezier(0.34, 1.56, 0.64, 1)

/* Bounce - Efeito de quique */
cubic-bezier(0.68, -0.55, 0.265, 1.55)
```

## Animações Tailwind

### Fade In

<div className="my-4 p-6 rounded-lg bg-gray-100 dark:bg-gray-800 animate-fade-in">
  Este elemento aparece com fade-in
</div>

```tsx
<div className="animate-fade-in">
  Este elemento aparece com fade-in

```

```css
/* tailwind.config.ts */

  'fade-in': 'fadeIn 0.2s ease-in',

    '100%': { opacity: '1' },
  },
}
```

## Framer Motion

Para animações mais complexas, utilizamos **Framer Motion**:

```tsx
import { motion } from 'framer-motion'

<motion.div
  initial={{ opacity: 0, y: 20 }}
  animate={{ opacity: 1, y: 0 }}
  transition={{ duration: 0.3 }}
>
  Conteúdo animado
</motion.div>
```

### Modal Open/Close

```tsx
<motion.div
  initial={{ opacity: 0, scale: 0.95 }}
  animate={{ opacity: 1, scale: 1 }}
  exit={{ opacity: 0, scale: 0.95 }}
  transition={{ duration: 0.2 }}
>
  Modal
</motion.div>
```

### Card Expansion

```tsx
<motion.div
  layout
  initial={false}
  animate={{ height: isOpen ? 'auto' : '80px' }}
  transition={{ duration: 0.3, ease: 'easeInOut' }}
>
  Card expansível
</motion.div>
```

### Scroll Animations

```tsx
import { motion, useScroll, useTransform } from 'framer-motion'

const { scrollYProgress } = useScroll()
const opacity = useTransform(scrollYProgress, [0, 0.5], [1, 0])

<motion.div style={{ opacity }}>
  Desaparece ao rolar
</motion.div>
```

## Acessibilidade

Sempre respeite a preferência do usuário por movimento reduzido:

```tsx
import { useReducedMotion } from 'framer-motion'

const shouldReduceMotion = useReducedMotion()

<motion.div
  animate={{
    scale: shouldReduceMotion ? 1 : 1.1
  }}
>
  Conteúdo
</motion.div>
```

### CSS Media Query

```css
@media (prefers-reduced-motion: reduce) {
  * {
    animation-duration: 0.01ms !important;
    animation-iteration-count: 1 !important;
    transition-duration: 0.01ms !important;
  }
}
```
