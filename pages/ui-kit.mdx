# UI Kit & Design System

Sistema de design completo usando **shadcn/ui** com tema neutro e profissional.

## 🎨 Filosofia de Design

### Princípios

1. **Neutralidade** - Paleta acromática (tons de cinza)
2. **Acessibilidade** - WCAG AA mínimo
3. **Consistência** - Usar apenas componentes shadcn
4. **Performance** - CSS variables, sem runtime CSS-in-JS
5. **Flexibilidade** - Dark mode nativo

## 📐 Espaçamento

O projeto usa a escala de espaçamento do Tailwind:

- **xs:** `0.5rem` (8px)
- **sm:** `0.75rem` (12px)
- **base:** `1rem` (16px)
- **lg:** `1.5rem` (24px)
- **xl:** `2rem` (32px)
- **2xl:** `3rem` (48px)

## 🔲 Border Radius

- **Padrão:** `0.5rem` (8px)
- **sm:** `0.375rem` (6px)
- **md:** `0.5rem` (8px)
- **lg:** `0.75rem` (12px)
- **xl:** `1rem` (16px)
- **full:** `9999px` (circular)

## 🌗 Dark Mode

O tema suporta dark mode nativamente. As cores se ajustam automaticamente:

- **Light:** Fundo branco, texto escuro
- **Dark:** Fundo escuro, texto claro
- **Transição:** Suave e automática

Use o toggle no topo da página para alternar.

## 🎯 Guidelines de Uso

### DO ✅

- Use componentes shadcn/ui sempre que possível
- Mantenha consistência com a paleta de cores
- Respeite a hierarquia tipográfica
- Use dark mode friendly colors
- Teste acessibilidade (contraste, navegação por teclado)

### DON'T ❌

- Não crie componentes customizados desnecessários
- Não use cores hardcoded (sempre use CSS variables)
- Não ignore semântica HTML
- Não use bibliotecas de UI externas
- Não adicione animações excessivas
