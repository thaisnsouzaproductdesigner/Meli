## Como Usar a Matriz

1. **Filtrar por Categoria**: Use os filtros para ver apenas oportunidades de Landing Page ou Gestão de Pagamento
2. **Ordenar por Prioridade**: As oportunidades já estão organizadas por impacto
3. **Explorar Detalhes**: Clique em qualquer card para ver o racional estratégico completo
4. **Navegar para Detalhes**: Use o botão "Ver detalhes" para acessar a página completa da oportunidade

---

## Critérios de Avaliação

### Impacto (Alto/Médio/Baixo)

Avaliado com base em:
- Potencial de aumento de conversão
- Redução de churn esperada
- Melhoria na satisfação do usuário (NPS)
- Valor percebido pelo cliente

### Esforço (Alto/Médio/Baixo)

Avaliado com base em:
- Complexidade técnica
- Tempo de desenvolvimento
- Dependências de sistemas
- Necessidade de testes/validação
